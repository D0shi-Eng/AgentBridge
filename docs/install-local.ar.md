# دليل التثبيت المحلي — AgentBridge على جهازك

> هذا الدليل يشغّل المنصة كاملة على جهاز محلي واحد: لوحة تحكم في المتصفح + خادم API + PostgreSQL (مع pgvector) + Redis + فحوص أمنية حية داخل حاوية معزولة. كل الخدمات مربوطة بـ`127.0.0.1` فقط ولا يُكشف أي منفذ على الشبكة.

## المتطلبات

| المتطلب | الملاحظة |
| --- | --- |
| Windows 10/11 | السكربتات PowerShell 5.1 وما فوق (لا تحتاج شيئًا إضافيًا) |
| Docker Desktop | يجب أن يكون عاملًا قبل `setup` و`start` — لن نشغّله نيابة عنك |
| Node.js ≥ 22.13 وpnpm | مطابقة `packageManager` في الجذر |
| Git | للسحب والتحديث فقط |
| مساحة | 5GB حرة على القرص الذي يُثبَّت فيه |

## التثبيت والتشغيل

```powershell
git clone https://github.com/D0shi-Eng/AgentBridge.git AgentBridge
cd AgentBridge
deploy\local\agentbridge.cmd setup    # مرة واحدة: أسرار مولدة محليًا + قاعدة بيانات + حساب إدارة
deploy\local\agentbridge.cmd start    # تشغيل كل الخدمات (قابل للتكرار بلا فقد بيانات)
```

ثم افتح اللوحة مباشرة بلا شاشة مفتاح:

```
agentbridge open
```

يفتح متصفحك الافتراضي على `http://127.0.0.1:3411/app` (ويشغّل الخدمات أولًا إن كانت متوقفة). أو اكتب العنوان بنفسك: فتح `/app` مباشرة يكفي — الجلسة المحلية تُؤسس تلقائيًا بلا معرّف مساحة عمل، وبلا مفتاح API، وبلا أي رمز في الرابط أو سجل المتصفح. مفتاح الإدارة (`runtime\secrets\admin-credential.key`) يبقى للوصول البرمجي إلى API ولأوامر التشغيل، لا لفتح اللوحة.

> منافذ افتراضية: API ‏3410، اللوحة 3411، PostgreSQL ‏3412، Redis ‏3413 — كلها على `127.0.0.1` وتُعدل من `runtime\local.env` قبل `setup`. ملاحظة: وكيل `/api` داخل اللوحة يُخبز وقت البناء، فتغيير المنفذ يستلزم `setup`/`update` من جديد.

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `agentbridge setup` | إعداد أولي idempotent: مجلدات منفصلة، أسرار مولدة، هجرات، حساب إدارة، بناء صورة العزل |
| `agentbridge start` | تشغيل PostgreSQL وRedis ثم API ثم اللوحة — يفشل برسالة واضحة إن غاب Docker أو انشغل منفذ |
| `agentbridge status` | حالة كل مكوّن (رمز خروج 0 سليم / 1 متدهور) |
| `agentbridge stop` | إيقاف كل شيء والبيانات تبقى في `runtime\data` |
| `agentbridge update` | سحب المصدر (fast-forward فقط) + بناء + هجرات + إعادة تشغيل إن كانت عاملة |
| `agentbridge backup [-Name x]` | نسخة `pg_dump` مضغوطة إلى `runtime\backups` مع بيان SHA-256 |
| `agentbridge restore -File <dump> -Yes` | استعادة نسخة (تأكيد صريح إلزامي) — توقف API وتعيده |

## أين تُحفظ الأشياء؟ (كلها داخل مجلد التثبيت وغير مرفوعة للمستودع)

| المسار | المحتوى |
| --- | --- |
| `runtime\data\postgres` | بيانات قاعدة البيانات (ملفات حية) |
| `runtime\data\redis` | بيانات Redis (appendonly) |
| `runtime\secrets` | الأسرار: `api.env` و`ops.env` و`compose.env` ومفتاح الدخول — محمية بـicacls (مالكها وSYSTEM فقط) |
| `runtime\logs` | سجلات API واللوحة |
| `runtime\backups` | النسخ الاحتياطية وبياناتها |
| `runtime\local.env` | منافذ وإعدادات الجهاز — بلا أسرار |

صور Docker الداخلية تبقى في مخزن Docker Desktop الافتراضي (WSL) — لم يُنقل هذا المخزن ولم تُغيَّر إعداداته العامة.

## الأخطاء المعتادة

- **«Docker مثبت لكن الخدمة لا تعمل»** — افتح Docker Desktop وانتظر جاهزيته ثم أعد الأمر.
- **«المنفذ X مشغول بعملية …»** — حرّر المنفذ أو غيّر المنافذ في `runtime\local.env` ثم أعد `setup`/`start`.
- **«التثبيت غير مكتمل»** — لم تنفذ `setup` بعد أو حُذف ملف من `runtime\secrets`.
- **فشل البدء بعد تحديث** — راجع آخر سطور `runtime\logs\api.err.log` أو `docker logs agentbridge-local-postgres`.
- **نسيت مفتاح الدخول؟** — لا يمكن استعادته (يُخزن hash فقط). احذف `runtime\secrets\admin-credential.key` ثم أعد `setup` لإنشاء مستأجر جديد (المعرف السابق محجوز).

## حدود الوضع المحلي (بصراحة)

- **TLS:** الاتصال محلي على `http://127.0.0.1` — يعتبره المتصفح سياقًا آمنًا، لكن هذه النسخة لا تُشغَّل HTTPS عبر الشبكة. بيئة TLS التدريبية موثقة عبر `STAGING_HTTPS=1` وتستلزم شهادة محلية وتثبيت ثقة يدوي موثق.
- **NODE_ENV=development:** وضع الإنتاج يرفض الإقلاع محليًا عمدًا (لا KMS خارجي معتمد بعد) — مفاتيح التوقيع هنا ثابتة ومولدة محليًا في `setup`.
- **الوضع mock:** `LLM_PROVIDER=mock` بلا أي مفتاح LLM. لمن يريد مزودًا حقيقيًا: أضف `ANTHROPIC_API_KEY`/`OPENAI_API_KEY` وغيّر `LLM_PROVIDER` في `runtime\secrets\api.env` ثم `agentbridge stop && agentbridge start`.
- **مستأجر واحد على جهاز واحد:** الحزمة تهيئ مساحة عمل مالكًا واحدة؛ تعدد المستأجرين ممكن عبر `agentbridge-ops` لكنه خارج هذه الحزمة.
- **بلا خدمة مستضافة:** لا يوجد خادم سحابي ولا Pages ولا منفذ عام — إيقاف الجهاز = إيقاف المنصة.

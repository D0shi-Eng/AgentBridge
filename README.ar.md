<h1 align="center">AgentBridge</h1>

<div align="center">

[<kbd>English</kbd>](README.md) · [<kbd>العربية</kbd>](README.ar.md)

</div>

<div dir="rtl">

يحوّل AgentBridge مواصفات OpenAPI إلى خوادم MCP بلغة TypeScript. من لوحة تعمل على جهازك وتفتحها في المتصفح، يمكنك رفع المواصفة ومتابعة التوليد والفحوص وقراءة النتيجة وتنزيل المخرجات. وتتوفر أداة سطر أوامر لمن يفضّل العمل من الطرفية.

**الترخيص:** [Apache-2.0](LICENSE) · **طريقة التشغيل:** على جهازك محليًا

**ابدأ من الصفر:** [دليل التثبيت على Windows](docs/install-local.ar.md) ← [دليل الاستخدام المصوّر خطوة بخطوة](docs/user-guide.ar.md). لا تحتاج إلى إحضار خدمة API خارجية، أو إدخال مفتاح API، أو كتابة معرّف مساحة عمل لفتح اللوحة محليًا. يشغّل أمر `open` المكوّنات الداخلية اللازمة تلقائيًا.

## ما هو AgentBridge؟

يدعم مواصفات `OpenAPI 3.0/3.1` بصيغتي JSON وYAML. يحلّل العمليات، ويقترح أدوات MCP، ويولّد شيفرة الخادم، ثم يعرض نتائج الفحوص. **تُمنح الشهادة الموقّعة فقط إذا استوفت المخرجات شروط السياسة وتوفرت الأدلة المطلوبة**؛ وإلا تظهر أسباب الرفض للمراجعة.

تسجّل الشهادة قرارًا يتعلق بناتج محدد وفق سياسة محددة. وهي لا تصادق على أمان الواجهة البرمجية الأصلية، ولا تغني عن مراجعتك للخادم المولّد قبل استخدامه.

## نوع المنتج: منصة ويب ذاتية الاستضافة

طريقة الاستخدام الأساسية هي **لوحة ويب تعمل على جهازك وتفتحها في المتصفح**. ليس المشروع تطبيقًا مستقلًا لسطح المكتب أو الهاتف. وتتوفر أداة سطر أوامر للمطوّر الذي لا يحتاج إلى اللوحة.

يفتح التثبيت الفردي اللوحة مباشرة. أما الوصول البرمجي وأنماط التشغيل الأخرى فلها ضوابط مصادقة مستقلة؛ ويقتصر الفتح المباشر على جهازك.

## المشكلة التي يحلها

تصف مواصفة OpenAPI واجهةً برمجية، لكنها لا تحدد أي عملياتها تصلح أدواتٍ للوكيل، أو الصلاحيات اللازمة لها، أو مدى سلامة سلوك الشيفرة المولّدة. يقدّم AgentBridge مسارًا قابلًا للتكرار من المواصفة إلى خادم MCP، مع نتائج فحوص وقرار يستطيع المطوّر مراجعتها.

## سير العمل: من OpenAPI إلى MCP

1. يقرأ المواصفة ويتحقق من بنيتها وحدودها.
2. يحلّل العمليات ويقترح أدوات MCP مرتبطة بمصادرها في المواصفة.
3. يولّد الخادم وبيان الأدوات.
4. يجري فحوصًا ساكنة، ويجري فحوصًا حية داخل حاوية Docker مقيّدة إذا توفرت بيئتها.
5. يطلب مراجعة بشرية عندما تشترطها السياسة، ثم يسجّل القرار والأدلة. غياب دليل حي إلزامي يمنع منح الشهادة.

![من مواصفة OpenAPI إلى خادم MCP ثم الفحوص والقرار](docs/architecture/diagrams/svg/03-openapi-pipeline.svg)

تشرح [وثيقة التنسيق](docs/orchestration.md) التفاصيل التنفيذية وراء هذا العرض المختصر.

## رسومات التوصيل المعمارية

يشرح [دليل الرسومات](docs/architecture/diagrams/README.ar.md) الرسومات الأربع عشرة ومسارات البيانات وحدود الثقة. ابدأ برسم [سياق النظام](docs/architecture/diagrams/svg/01-system-context.svg)، ثم رسم سير العمل أعلاه، ثم رسم [الموقع التعريفي مقابل المنصة العاملة](docs/architecture/diagrams/svg/14-website-vs-platform.svg). الموقع التعريفي يشرح المنتج؛ أما اللوحة والخدمات فتعمل من تثبيتك المحلي.

## ماذا يمكنك فعله؟

- قراءة مواصفات OpenAPI 3.0/3.1 بصيغتي JSON وYAML وتوليد خادم MCP بلغة TypeScript.
- تسجيل نتائج الفحوص الساكنة، ونتائج الفحوص الحية عند توفر بيئة Docker اللازمة.
- توقيع شهادة للتشغيل المؤهل، وإتاحة نتيجة تحقق محدودة الحقول من نسخة API تشغّلها أنت.
- متابعة التشغيل والنتائج من لوحة المتصفح، أو استخدام أداة سطر الأوامر مع مزوّد المحاكاة المضمّن.
- الاحتفاظ ببيانات التثبيت المحلي بعد إعادة التشغيل، مع أوامر للحالة والإيقاف والتحديث والنسخ الاحتياطي لقاعدة البيانات والاستعادة.

## المعمارية

يضم `apps/` خادم API المبنيّ على Fastify، ولوحة Next.js، وأداة سطر الأوامر. ويضم `packages/` وحدات قراءة المواصفات والتحليل والتوليد والفحص والتنسيق وما يدعمها. يستخدم التثبيت المحلي الكامل PostgreSQL مع pgvector وRedis؛ وتعمل الفحوص الحية في حاوية Docker منفصلة ومقيّدة.

![مكوّنات النظام وحدود الثقة بينها](docs/architecture/diagrams/svg/01-system-context.svg)

راجع [وثيقة المعمارية](docs/architecture.md) و[دليل الرسومات](docs/architecture/diagrams/README.ar.md) لمعرفة حدود المكوّنات ومسارات البيانات.

## نموذج الأمان وحدوده

يربط التثبيت الفردي خدماته افتراضيًا بالعنوان `127.0.0.1`، ويولّد أسراره على جهاز المستخدم. تفترض الجلسة التلقائية أن البرامج التي تعمل باسم مستخدم نظام التشغيل نفسه موثوقة؛ **لا تكشف هذا الوضع عبر الشبكة**. وتُقيّد حاوية الفحوص الحية، لكن عزلها يعتمد أيضًا على سلامة الجهاز المضيف وإعداد Docker.

تصف الشهادة نتيجة فحوص محددة على ناتج محدد، ولا تمنح ضمانًا مطلقًا. وإذا اخترت مزوّد نماذج خارجيًا، فقد تُرسل إليه بيانات المواصفة وقد تتحمل تكلفة استخدامه. اقرأ [وثيقة الأمان](docs/security.md) قبل معالجة مواصفات حساسة أو تغيير إعدادات الشبكة.

## البدء محلياً

للتثبيت الفردي الموثق، تحتاج Windows 10/11، وDocker Desktop قيد التشغيل، وNode.js بإصدار `22.13` أو أحدث، وإصدار `pnpm` المحدد في [`package.json`](package.json)، وGit، ومساحة قرص حرة لا تقل عن 5 جيجابايت.

<div dir="ltr">

```powershell
git clone https://github.com/D0shi-Eng/AgentBridge.git
cd AgentBridge
deploy\local\agentbridge.cmd setup
deploy\local\agentbridge.cmd open
```

</div>

ينشئ `setup` الإعدادات والأسرار المحلية ومخازن البيانات وصورة العزل. ويشغّل `open` الخدمات المتوقفة عند الحاجة، ثم يفتح اللوحة على `http://127.0.0.1:3411/app`. لا يحتاج مزوّد المحاكاة الافتراضي إلى مفتاح نموذج خارجي.

راجع [دليل التثبيت على Windows](docs/install-local.ar.md) للمتطلبات وحل المشكلات، و[دليل الاستخدام المصوّر](docs/user-guide.ar.md) لرفع المواصفة وقراءة النتيجة. لا ترفع `runtime/` أو النسخ الاحتياطية أو الأسرار المولّدة إلى Git أو بلاغ عام.

## جرّب سطر الأوامر — بلا مفاتيح وبلا خدمات

لتجربة مسار المعالجة دون تشغيل اللوحة أو قاعدة البيانات:

<div dir="ltr">

```powershell
pnpm install --frozen-lockfile
pnpm exec tsx apps/cli/src/main.ts --spec tests/fixtures/mini-petstore.yaml --out ./ab-out
```

</div>

يستخدم هذا المثال مزوّد المحاكاة المضمّن، ولا يحتاج خدمة خارجية. **من المتوقع أن يسجّل التشغيل رفضًا، لا شهادة ممنوحة، عند غياب دليل الفحص الحي.** يحتوي مجلد المخرجات على الملفات المولّدة وسجل القرار. وللفحوص الحية متطلبات Docker إضافية؛ راجع [وثيقة الأمان](docs/security.md).

## تشغيل المنصة محليًا وصيانتها

الحزمة الموصى بها هي `deploy/local/` المذكورة أعلاه. تشغّل اللوحة وAPI وPostgreSQL وRedis ودعم العزل على جهاز Windows واحد. استخدم أمر `status` لمعرفة حالة الخدمات، و`stop` لإيقافها. يشرح [دليل التثبيت](docs/install-local.ar.md) التحديث والنسخ الاحتياطي والاستعادة، وما الذي تتضمنه نسخة قاعدة البيانات.

صُممت حزمة التشغيل المرفقة لجهاز واحد، وترتبط افتراضيًا بعنوانه المحلي. هي لا تنشر لوحتك للآخرين؛ كل مستخدم يشغّل نسخته على جهازه.

## اختبارات التكامل الحية الاختيارية

تحتاج بعض الاختبارات إلى خدمات فعلية مثل PostgreSQL وRedis وDocker. وقد تُتخطى مع تسجيل السبب إذا لم تتوفر متطلباتها. اقرأ أعداد الاختبارات الناجحة والفاشلة والمتخطاة في تشغيلك؛ نجاح المجموعة الافتراضية لا يعني تنفيذ جميع سيناريوهات التكامل المشروطة.

## بنية المستودع

- `apps/`: خادم API ولوحة الويب وأداة سطر الأوامر.
- `packages/`: وحدات المنتج والمكوّنات المشتركة.
- `deploy/local/`: أوامر التثبيت والتشغيل والصيانة المحلية.
- `docker/`: ملفات بناء بيئة العزل وتشغيلها.
- `docs/`: أدلة الاستخدام والأمان والرسومات المعمارية.
- `tests/`: الاختبارات والبيانات الاصطناعية المستخدمة فيها.
- `website/`: موقع تعريفي ثابت، وليس المنصة العاملة.

## متغيرات الإعداد

مرجع المتغيرات هو [`.env.example`](.env.example). يبدأ التثبيت المحلي بـ`LLM_PROVIDER=mock` من دون مفتاح لمزوّد خارجي. إذا اخترت مزوّدًا عبر الشبكة، فأضف مفتاحك **إلى إعدادات جهازك فقط**، وراجع شروطه لمعالجة البيانات والتكلفة. لا تودع الأسرار أو بيانات التشغيل أو النسخ الاحتياطية في المستودع.

## الاختبارات والتحقق

من جذر المستودع، وبعد تجهيز المتطلبات:

<div dir="ltr">

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

</div>

تفحص [بوابة CI](.github/workflows/ci.yml) الوثائق والتبعيات والتراخيص والأسرار ونواتج البناء أيضًا. نجاح تشغيل سابق للبوابة لا يغني عن اختبار تثبيتك أنت، ويجب قراءة نتائج الاختبارات الحية المشروطة على حدة.

## المساهمة والإبلاغ الأمني

للمساهمة، اقرأ [دليل المساهمة](CONTRIBUTING.md) و[مدونة السلوك](CODE_OF_CONDUCT.md). وللبلاغات الأمنية، راجع [سياسة الأمن](SECURITY.md) قبل التواصل، ولا تنشر تفاصيل ثغرة غير مصححة في قضية عامة.

## حدود التشغيل

- حزمة التثبيت بأمر واحد مخصصة لـWindows. يتحقق CI من الشيفرة على Linux، لكنه لا يثبت أن مُثبّت Windows يعمل عليه.
- تحتاج الفحوص الحية إلى Docker عامل. ولا تغني قيود الحاوية عن تأمين الجهاز المضيف ومراجعة الخادم المولّد.
- يحتاج مزوّد النموذج الخارجي إلى مفتاحك وقد يفرض رسوم استخدام. أما مزوّد المحاكاة فلا يفرض رسوم مزوّد، لكنه لا يمثل كل سلوك خدمة حقيقية.
- يشمل أمر النسخ الاحتياطي المرفق بيانات PostgreSQL. تحقّق من طريقة حفظ الملفات والإعدادات الأخرى قبل اعتباره خطة استعادة شاملة.
- لا يقدّم المشروع خدمة مُدارة عبر الإنترنت؛ يعمل كل تثبيت ببياناته على جهاز صاحبه. يشرح [دليل التثبيت](docs/install-local.ar.md) إعدادات التشغيل المحلي، وتوضح [وثيقة الأمان](docs/security.md) حدوده التقنية.

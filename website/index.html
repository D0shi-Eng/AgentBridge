AgentBridge
العربية English

من مواصفة OpenAPI إلى خادم MCP قابل للمراجعة — بشهادة موقعة وقابلة للتحقق

AgentBridge منصة ويب ذاتية الاستضافة تحلل واجهاتك البرمجية، وتقترح أدوات لوكلاء الذكاء الاصطناعي، وتولّد خادم MCP، وتهاجمه بفحوص أمنية داخل صندوق معزول، ثم تمنح — أو ترفض — شهادة موقعة مربوطة ببصمة الناتج.

  • ترخيص Apache-2.0
  • يعمل محليًا بلا مفاتيح (مزود LLM محاكى)
  • للتقييم المحلي — التشغيل الإنتاجي غير مدعوم في هذه النسخة

نوع المنتج: منصة ويب ذاتية الاستضافة

AgentBridge منصة ويب تستضيفها بنفسك — ليست تطبيق Android أو iOS، وليست تطبيق سطح مكتب. مجلد apps/ يعني الوحدات القابلة للتشغيل:

apps/api

خادم ويب Fastify يقدم REST وSSE ونقطة التحقق العلنية.

apps/dashboard

لوحة ويب Next.js تفتحها من المتصفح: رفع المواصفات ومتابعة المسار وHITL.

apps/cli

أداة سطر أوامر تشغّل مسار المعالجة نفسه على ملفاتك محليًا.

طريقتا الاستخدام: (1) خدمة ويب تشغّلها على جهازك أو خادمك وتفتحها من المتصفح، أو (2) سطر أوامر للمطورين فوق شيفرة المصدر المفتوحة.

فتح مستودع المشروع للجمهور لا يشغّل أي خدمة ولا يستضيف شيئًا — لا توجد نسخة مستضافة من AgentBridge.

هذا الموقع ليس المنصة

هذه الصفحات موقع ثابت للتعريف والتوثيق. المنصة الكاملة هي ما تشغّله أنت محليًا من المستودع. الموقع الثابت لا ينفذ:

  • واجهة Fastify البرمجية أو بث SSE الخلفي
  • PostgreSQL أو Redis أو pgvector
  • صندوق Docker المعزول أو توليد وفحص MCP الكامل
  • تسجيل دخول حقيقي أو تخزين أي أسرار أو بيانات مستخدمين

بلا نماذج إدخال، وبلا تتبع أو تحليلات، وبلا أي طلبات خارجية — ملفات جاهزة للقراءة فقط.

كيف يعمل

مسار معالجة حتمي من ثماني مراحل مع حلقة إصلاح محدودة: الاستيعاب ← التحليل ← تصميم الأدوات (باستشهادات إلزامية) ← التوليد الحتمي ← التحصين (12 فحصًا ساكنًا و8 فحوص حية داخل حاوية مقيدة) ← التقييم ← المراجعة البشرية للأدوات الحساسة (HITL) ← الشهادة. الدرجة 85 فأعلى وصفر نتائج حرجة تمنح شهادة «Agent-Ready Verified» موقعة Ed25519 ومربوطة ببصمة SHA-256 للناتج.

المعمارية باختصار

نمطية متجانسة بحدود سداسية: packages/ وحدات بمنافذ ومحولات قابلة للفك إلى خدمات لاحقًا، وapps/ طبقة تجميع. قاعدة التبعية حديدية: النطاق الدلالي لا يعتمد البنية التحتية، والحتمي أولًا — الخوارزميات قبل نداء النماذج، وكل خرج نموذجي يمر عبر تحقق Zod وطبقات الحقيقة.

الأمن وحدوده بصراحة

  • أسرار المنصة من البيئة حصرًا مع تحقق Zod عند الإقلاع وسجلات محجوبة.
  • مفاتيح المستأجرين مجزأة بـ scrypt، واعتماديات الواجهات العلوية مغلفة AES-256-GCM.
  • الفحوص الحية داخل حاوية بجذر قراءة-فقط ومستخدم غير جذر وشبكة محصورة على localhost.
  • عزل المستأجرين بنيوي مع RLS ودور قاعدة بيانات مقيد.
  • شهادة موقعة + نقطة تحقق علنية بقائمة حقول بيضاء صارمة.

الحدود: الشهادة توثق تشغيل سياسة واحدة لا أمانًا مطلقًا؛ والصندوق رهين إعداد مضيف Docker لديك؛ وسياسة الخروج الشبكية العامة وKMS الخارجي غير منفذين؛ ولا يوجد أي نشر إنتاجي لهذا النظام.

التشغيل الذاتي في دقيقتين (بلا مفاتيح)

سطر الأوامر — تجربة أسرع

# يتطلب Node.js ≥ 20 وpnpm
pnpm install
pnpm exec tsx apps/cli/src/main.ts \
  --spec tests/fixtures/mini-petstore.yaml --out ./ab-out

تظهر أحداث المراحل في الطرفية، وفي ./ab-out: خادم MCP مولَّد + certificate.json + badge.svg + events.ndjson. رمز الخروج 0 = شهادة منححة، 2 = رفض موثق.

المنصة الكاملة (خدمة ويب)

docker compose -f docker-compose.dev.yaml up -d   # PostgreSQL+pgvector وRedis
pnpm --filter @agentbridge/infra exec prisma generate
pnpm --filter @agentbridge/infra exec prisma migrate deploy      # على قاعدة فارغة
pnpm --filter @agentbridge/api start        # الواجهة على :3000
pnpm --filter @agentbridge/dashboard dev    # اللوحة على :3001

إنشاء مساحة العمل والمفتاح يتم عبر agentbridge-ops onboard-tenant (المفتاح الخام يُكتب ذرياً في ملف لا في السجلات). التسلسل الكامل المتحقق منه ومتغيرات البيئة في README المستودع.

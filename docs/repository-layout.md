## قواعد القراءة

1. **اتجاه التبعيات:** `apps` تجميع، و`packages` تنفيذ، و`shared` تعريف — المصدر يتجه نحو العقود الداخلية فقط، والنطاق الدلالي لا يستورد البنية التحتية أبداً.
2. **الحتمية أولًا:** كل ما يمكن أن يكون برمجياً حتمياً هو حتمي؛ والنماذج اللغوية للتصميم والتقييم والإصلاح فقط، وخرجها يمر عبر Zod وطبقات الحقيقة.
3. **كل طبقة تعرف ما تحتها فقط:** المنافذ في `packages/memory` والنطاق الدلالي؛ والمحولات الحية في `packages/infra` وحدها.
4. **لا أسرار في الشجرة:** المرجع `.env.example` بقيم مواضع حفظ، والقيم الحقيقية خارج Git عبر `.env`.

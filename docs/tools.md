# أدوات الوكلاء (Internal Tools)

> الأدوات هي القدرات الوحيدة التي يستطيع الوكيل تنفيذها. مبدأ **الحد الأدنى للصلاحية**: كل وكيل يرى أداته فقط. كل أداة: مدخل Zod، مخرج Zod، وسجل تدقيق تلقائي.

## الكتالوج

| الأداة | الوكيل | الوظيفة | الحتمية |
| --- | --- | --- | --- |
| `search_spec` | المصمم | بحث نصي/دلالي في المواصفة المطبّعة (يعيد مسارات + مقاطع) | نعم + متجهات |
| `get_endpoint_details` | المصمم | إرجاع endpoint واحد كاملاً بمعاملاته وردوده | نعم 100% |
| `validate_tool_design` | المصمم | فحص تصميم أداة مقابل endpoints المرتبطة (هل الادعاءات موجودة فعلاً؟) | نعم 100% |
| `run_security_suite` | المدقق | تشغيل مجموعة اختبارات التحصين على artifact | نعم 100% |
| `read_artifact_source` | المدقق | قراءة ملف من الخادم المولد (قراءة فقط، داخل sandbox) | نعم 100% |
| `grep_artifact` | المدقق | بحث نمطي في كود الخادم المولد | نعم 100% |
| `simulate_tool_call` | المقيم | استدعاء تجريبي لأداة ضد خادم mock محلي وإرجاع النتيجة | نعم 100% |
| `apply_patch` | المصلح | تطبيق patch موضعي على artifact مع نسخ احتياطي تلقائي | نعم 100% |
| `retest_scope` | المصلح | إعادة تشغيل الاختبارات المتأثرة بالـ patch فقط | نعم 100% |

## عقد الأداة الموحد (Tool Contract)

كل أداة تنفذ نفس الواجهة:

```ts
interface AgentTool<TIn, TOut> {
  /** اسم فريد يُعرض للنموذج */
  readonly name: string;
  /** مخطط تحقق المدخل — يرفض قبل التنفيذ */
  readonly inputSchema: ZodSchema<TIn>;
  /** مخطط تحقق المخرج — يرفض بعد التنفيذ */
  readonly outputSchema: ZodSchema<TOut>;
  /** التنفيذ الفعلي — دوال حتمية فقط */
  execute(input: TIn, ctx: ToolContext): Promise<Result<TOut, AppError>>;
}
```

## قواعد ملزمة

1. **لا أداة تتصل بالشبكة الخارجية** إلا `simulate_tool_call` وهو مقيد بـ localhost.
2. **كل نداء أداة** يسجل في سجل التدقيق: من، ماذا، متى، كم استغرق، هل نجح.
3. **فشل الأداة** يعود كـ `Result.err` منظّم — لا استثناءات تعبر حدود الوكيل.
4. **الأداة صغيرة**: ملف واحد لكل أداة في `packages/agents/src/tools/`.

# دليل الاستخدام المصوّر — من التثبيت إلى قراءة النتيجة

[English](user-guide.en.md) · العربية

هذا الدليل للمستخدم الذي يريد تشغيل AgentBridge على جهاز Windows ثم إنجاز تجربة كاملة من المتصفح. تظهر في الصور بيانات تجريبية، وقد تختلف الأسماء والنتائج في تشغيلك. **لا تحتاج إلى خدمة API خارجية، ولا إلى إدخال مفتاح API أو معرّف مساحة عمل لفتح اللوحة المحلية.** لدى التطبيق خدمة خلفية يشغّلها بنفسه؛ ليست شيئًا عليك الحصول عليه من جهة أخرى.

## 1. جهّز جهازك

تحتاج Windows 10/11 مدعومًا من أدواتك، و5 جيجابايت حرة على قرص التثبيت. ثبّت [Git](https://git-scm.com/install/windows)، و[Node.js](https://nodejs.org/en/download) بإصدار `22.13` أو أحدث، و[Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) وفق متطلبات جهازك. افتح Docker Desktop وانتظر حتى تصبح خدمة الحاويات جاهزة. بعد تثبيت Node.js، ثبّت إصدار `pnpm` المحدد في [`package.json`](../package.json):

```powershell
npm install --global pnpm@11.22.0
```

في نافذة PowerShell جديدة، تأكد من أن `git --version` و`node --version` و`pnpm --version` و`docker info` تعمل قبل المتابعة. إذا تعثر أحدها، راجع دليل الأداة الرسمي أو [دليل تثبيت AgentBridge](install-local.ar.md). لا يلزم مفتاح لمزوّد ذكاء اصطناعي للتجربة الافتراضية؛ يستخدم التثبيت مزوّد المحاكاة `mock`.

## 2. ثبّت البرنامج وافتح اللوحة

افتح PowerShell في المجلد الذي تريده للتثبيت، ثم نفّذ الأوامر التالية بالترتيب:

```powershell
git clone https://github.com/D0shi-Eng/AgentBridge.git
cd AgentBridge
deploy\local\agentbridge.cmd setup
deploy\local\agentbridge.cmd open
```

قد يستغرق `setup` وقتًا لأنه يجهّز التبعيات وقاعدة البيانات وصورة العزل، ويولّد أسرار التثبيت **على جهازك**. بعده يشغّل `open` الخدمات اللازمة ويفتح `http://127.0.0.1:3411/app` في متصفحك. يمكنك فتح العنوان بنفسك لاحقًا. لا توجد شاشة تطلب منك معرّف مساحة عمل أو مفتاح API في الوضع المحلي الفردي.

إذا لم تفتح اللوحة، تأكد من عمل Docker Desktop ثم نفّذ `deploy\local\agentbridge.cmd status`. يشرح [دليل التثبيت](install-local.ar.md) الأخطاء الشائعة والإيقاف والتحديث.

![اللوحة المحلية بعد فتحها في المتصفح](guide/images/02-dashboard.png)

## 3. أنشئ مشروعًا واختره

في قسم «مشاريعي» أسفل اللوحة، اكتب اسمًا مثل «تجربة أولى» ثم اضغط «إضافة مشروع». ارجع إلى نموذج «مواصفة OpenAPI جديدة» أعلى الصفحة واختر المشروع من القائمة. المشروع هنا ينظم عملياتك داخل تثبيتك المحلي؛ لا تحتاج إلى إنشاء مساحة عمل أو إدخال معرّفها.

![قسم المشاريع ونموذج المواصفة في اللوحة](guide/images/03-upload-spec.png)

## 4. أضف مواصفة OpenAPI وابدأ التشغيل

للتجربة الأولى، ارفع الملف التجريبي `tests/fixtures/mini-petstore.yaml` من نسخة المستودع التي ثبتّها، أو الصق محتواه في مربع النص. بعد اختيار المشروع، اضغط «ابدأ التشغيل». تقبل الواجهة ملف YAML أو JSON ضمن الحد المعروض فيها؛ إذا رفضت ملفًا كبيرًا، راجع رسالة الخطأ بدل افتراض أنه عولج.

لا تضع بيانات اعتماد أو أسرارًا حقيقية في مواصفة التجربة. إذا اخترت لاحقًا مزوّد نموذج خارجيًا، فاقرأ [حدود معالجة البيانات](security.md) قبل رفع مواصفات حساسة.

## 5. تابع التشغيل واقرأ القرار

تفتح صفحة العملية وتعرض تقدمها وأحداثها. الصورة التالية مثال **لتشغيل اكتمل**؛ عدد الخطوات والدرجة المعروضتان فيها نتيجة لتلك التجربة، وليستا وعدًا بنتيجة مماثلة لكل مواصفة.

![صفحة العملية وتقدمها وقرارها في تجربة مصوّرة](guide/images/04-run-stages.png)

في بطاقة القرار، اقرأ الحالة والسبب والدرجة. إذا مُنحت شهادة، ستظهر روابط تنزيل الشهادة وملفات الناتج ومعرّف التحقق. وإذا رُفضت، اقرأ سبب الرفض والأدلة الناقصة؛ **وجود ناتج مولّد لا يعني منح شهادة تلقائيًا**. قد يتطلب الفحص الحي Docker عاملًا وإعداد العزل الذي يوفره التثبيت المحلي.

![بطاقة القرار والتنزيلات وسجل الأحداث في التجربة المصوّرة](guide/images/05-certificate.png)

## 6. تحقّق من الشهادة، إن مُنحت

افتح رابط التحقق الظاهر في بطاقة القرار. تعرض الصفحة نتيجة التحقق وحقولًا محدودة، مثل الدرجة وبصمة الناتج الذي فُحص. إنها تسجّل قرار فحص **لناتج محدد**، ولا تغني عن مراجعة أمان الواجهة الأصلية والخادم المولّد قبل استخدامهما. إذا لم تُمنح شهادة فلن يكون لديك رابط شهادة ممنوحة لتجربته.

![صفحة التحقق من شهادة مُنحت في تجربة مصوّرة](guide/images/06-verify-public.png)

## بعد التجربة

- لإيقاف الخدمات مع الاحتفاظ بالبيانات: `deploy\local\agentbridge.cmd stop`.
- لفتح اللوحة لاحقًا: `deploy\local\agentbridge.cmd open` من مجلد التثبيت.
- للنسخ الاحتياطي والتحديث والاستعادة: اتبع [دليل التثبيت](install-local.ar.md). النسخة المرفقة تغطي PostgreSQL، فلا تعدّها وحدها نسخة شاملة لكل الملفات والإعدادات.

هذه الصور الخمس من واجهة محلية ببيانات تجريبية؛ لا توجد هنا صورة لعملية تثبيت على جهاز جديد. الأوامر والخطوات المكتوبة هي مرجع تلك العملية. قد يتغير شكل الواجهة بمرور الوقت، وعند اختلافه اتبع أسماء العناصر ورسائل الخطأ في نسختك المثبتة.

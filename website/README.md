# website/ — الموقع الثابت (تعريفي وتوثيقي)

موقع ثابت ثنائي اللغة (عربي `dir="rtl"` وإنجليزي `dir="ltr"`) للتعريف بالمشروع
وتوثيقه. **هذا الموقع ليس المنصة** — راجع قسم «هذا الموقع ليس المنصة» فيه.

## بيانات صارمة

- **بلا جافاسكربت إطلاقًا**، وبلا نماذج إدخال، وبلا تتبع أو تحليلات، وبلا طلبات خارجية.
- كل الروابط والمصادر نسبية، فيعمل الموقع تحت أي مسار أساس (منها `/AgentBridge/`).
- الوصولية WCAG 2.2 AA: رابط تخطٍ، معالم دلالية، تباين كافٍ، تركيز ظاهر،
  أهداف لمس ≥ 44px، واحترام `prefers-reduced-motion`.
- لا يملك أي workflow صلاحيات `pages: write` أو `id-token: write`، ولا يوجد
  workflow نشر إطلاقًا — **قرار النشر للمالك وحده**.
- `ci.yml` يشغّل `website/check.mjs` فقط: فحص بنية وروابط ومبادئ الصفحات.

## الأوامر

```bash
node website/check.mjs   # فحص الصدق والروابط (نفسه في CI)
node website/build.mjs   # تجميع نسخة قابلة للنشر في website/dist
```

`website/dist/` يكرر البنية النسبية (`website/` + `docs/assets` + `docs/architecture/diagrams/svg`)
فتبقى الروابط صحيحة عند نشر المجلد كما هو. أضِف `website/dist/` إلى تجاهل Git المحلي
إن أعدت بناءه — ولا تُدعه إلى المستودع.

## ماذا ينشر لاحقًا (قرار الملك غير منجز)

نشر الموقع على GitHub Pages أو أي مضيف ثابت قرار مستقل لم يُتخذ؛ إعداده
اللاحق (مصدر النشر، النطاق) يتم بـworkflow مخصص حين يأمر المالك صراحة.
